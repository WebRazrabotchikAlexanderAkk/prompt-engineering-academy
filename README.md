# Prompt Engineering Academy

Интерактивный образовательный портал по prompt engineering для пользователей с базовым опытом работы с AI. Теория в шести статьях соединяется с упражнениями внутри текста, а итоговый тест проверяет понимание и применение знаний.

## Статус

Проект находится на стадии спецификации. Код приложения, package manager manifest и Git-репозиторий ещё не созданы.

## Подтверждённый MVP

- Astro + React + TypeScript.
- Шесть русскоязычных учебных статей.
- 18 inline-упражнений.
- 10 типов упражнений, включая `ContextBudget`.
- Банк из 24 заданий и итоговая выборка из 12.
- Первичный и финальный результаты после одной корректирующей попытки.
- Локальное сохранение прогресса.
- Светлая и тёмная темы.
- XP, достижения, награды и итоговые ранги.
- WCAG 2.2 AA, клавиатурное управление и mobile-first интерфейс от 360 px.
- Публичный репозиторий `prompt-engineering-academy` и GitHub Pages на этапе публикации.

## Планируемая структура продукта

- Главная страница объединяет учебный маршрут и каталог шести статей.
- Каждая статья является отдельной учебной миссией.
- Итоговый тест доступен сразу, но интерфейс рекомендует проходить статьи последовательно.
- Экран результата входит в страницу теста.
- Страница «О проекте» кратко объясняет назначение портала.

## Локальный запуск

Команды запуска появятся после создания приложения и `package.json`. До этого момента README намеренно не содержит неподтверждённых команд.

## Открытые решения

До реализации должны быть отдельно согласованы визуальная система, CSS/UI-подход, drag-and-drop средство, точные правила XP и наград, а также детали GitHub Pages. Полный список находится в [DECISIONS.md](docs/DECISIONS.md).

## Ограничения

В MVP нет регистрации, backend, базы данных, реального AI API и синхронизации между устройствами.
