Исходные количественные условия выполнены локально; перед передачей ссылки на репозиторий нужно сохранить и отправить исходники.

## Состав и исключения

- Проверен список файлов, который Git видит как отслеживаемые и новые с учётом `.gitignore`. В исходном комплекте 150 файлов, около 2.8 МБ; добавление этого отчёта увеличивает число файлов до 151.
- В комплект входят `src/`, `public/`, `tests/`, `scripts/`, документация, `package.json`, `package-lock.json` и настройки Astro, TypeScript, Vitest и Playwright. Наличие `package-lock.json` позволяет устанавливать зафиксированные версии через `npm ci`.
- `.gitignore` исключает `node_modules/`, `dist/`, `.astro/`, отчёты покрытия и браузерных проверок, `.env`, `.env.*` и журналы `*.log`. Проверена применимость правил через `git check-ignore`. Исключения уже настроены и не требуют удаления пользовательских файлов.
- В кандидатах на добавление не обнаружены файлы окружения, приватных ключей и совпадения с проверенными распространёнными форматами секретных ключей или присвоениями секретов. Это проверка состава и характерных шаблонов, а не гарантия распознавания любого возможного секрета.
- Абсолютные пути локального компьютера найдены только в исторических протоколах `FINAL_ACCEPTANCE.md` и `IMPLEMENTATION_AUDIT.md`. Они служат ссылками на прежние доказательства; запуск приложения от них не зависит. Персональные настройки и старые временные доказательства не включаются в комплект исходников.

## Воспроизведение

Среда проверки: Windows, Node.js 24.16.0, npm 11.13.0, установленный Microsoft Edge. Из папки с исходниками:

```sh
npm ci
npm run dev
```

Открыть `http://127.0.0.1:4321/`, перейти к первой статье, ответить на упражнение, затем открыть итоговый тест. Подробный сценарий и ограничения изложены в `README.md`.

```sh
npm test -- --maxWorkers=1
npm run typecheck
npm run build
npm run test:e2e -- --project=edge --workers=1
npm run test:links
npm run test:static
npm run check:static
npm run test:static-browser
```

В ограниченной среде Codex для Vitest заданы `TEMP` и `TMP`, указывающие на разрешённую временную папку. Браузерные команды запускают и останавливают собственные локальные серверы. Чистая копия для установки находится вне комплекта исходников и не использует исходный `node_modules`.
